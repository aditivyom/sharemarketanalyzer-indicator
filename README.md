# sharemarketanalyzer-indicator
A stock market graph analyzer featuring a custom technical indicator to visualize price movements, analyze market trends, and identify potential trading signals. Designed to simplify technical analysis through interactive charts and market data visualization, supporting informed analysis for educational and research purposes.
---------------------------------------------------
Install:  pip install yfinance pandas numpy matplotlib
Run:      python live_market_analyzer.py

Select an index/stock, pick a timeframe, press START LIVE.
The candlestick chart refreshes automatically and the engine gives a
BUY / SELL / HOLD signal with entry, stop-loss and target.

DISCLAIMER: Educational tool. Indicator signals are NOT guaranteed.
Never trade money you cannot afford to lose. Not financial advice.
